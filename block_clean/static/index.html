San Francisco 311

Block Clean

Open 311 jobs from the last 180 days that a neighbor can finish on foot. Mistral reads each request type and keeps the ones a person can do. Log a before and after photo, and the shops within a few blocks get the picture.

Optional. In your Google account, turn on 2-step verification, then create an app password. We encrypt it in Elasticsearch and only use it to send the cleanup note, with both photos, from your Gmail. The password is never shown again.

    Shops nearby

    The city business list has no emails. A shop joins with an address, and we place it on the map. Shops shown on a case are the ones within 400 meters whose description is closest to that cleanup. A joined shop in that range gets the after photo, with reply-to set so they can write back.
